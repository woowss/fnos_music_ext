# §0.2 认证会话对比实验计划（待用户登录后执行）

> **计划，不是执行记录。** 目的：完成 §0.2 唯一剩余关键未知——`trim_http_cgi` 在**带有效会话**时是否剥离/覆盖客户端自带的 `X-Trim-*` 头。
> 前置：用户在 DSH 浏览器（蓝色边框窗口）自行完成 `https://192.168.0.106:11026` 的访问码 + fnOS 登录。**Lead 不接触、不索取、不记录账号/密码/2FA/会话 cookie。**
> 关联：`docs/TRUSTED_INGRESS_READONLY_EVIDENCE_20261107.md`（§0.2 只读证据与 L1/L2 边界更正）、`docs/G0_TRUSTED_INGRESS.md`（R1 未定案）。

## 1. 只做只读 GET，边界

- 只请求只读端点：`GET /app/fnmusic-ext/api/manual-save/status`（返回配置状态，无写副作用）。
- **不触发**任何写接口（`POST /api/manual-save/*`、playlist 写端点、保存、发布、删除）。
- 不导出/不打印/不落盘 cookie、token、访问码、完整 URL 的敏感部分。
- 若页面或窗口不是用户已登录的 DSH 浏览器标签，则停止并请用户确认，不操作其它窗口。

## 2. 观测层级与判定

### L1：浏览器导航（必做，只读）

1. 在已登录的 DSH 浏览器标签打开 `https://192.168.0.106:11026/app/fnmusic-ext/`，确认扩展页面正常加载（而非安全码页）。
2. 打开 `https://192.168.0.106:11026/app/fnmusic-ext/api/manual-save/status`，记录：HTTP 状态、响应体（脱敏：只保留结构/布尔值/固定码，不复制路径细节）、页面实际内容是否 JSON。
3. 判定：
   - 200 + JSON（`enabled` 等字段）→ 证明**已认证会话可经 nginx → trim_http_cgi → 网关**到达应用；这是 §0.2 认证链路正向证据。
   - 安全码页/401/403 → 会话未通过或安全码未完成，记录并停止。

### L2：伪造头对比（若可安全注入；可选但关键）

目标：对比"正常请求"与"正常请求 + 客户端自带 `X-Trim-Isadmin: true`"的行为。

- **若** DSH 浏览器提供可用的 CDP/请求头注入能力（可设置 `Runtime.evaluate` 发起 `fetch(..., {headers:{...}})`），则：
  1. 在页面上下文执行只读 `fetch` 到上述 status 端点，A 组不带伪造头、B 组带 `X-Trim-Isadmin: true`（保留会话 cookie 自动携带）。
  2. 记录两组的状态码与响应摘要（不打印 cookie）。
  3. 判定：
     - B 组 **400/`invalid_identity_claim`（重复 identity 头）或 403** → `trim_http_cgi` 注入自身 claim + 应用拒绝重复头 → **R1 风险关闭**（伪造头不能覆盖）。
     - B 组 **200 且与 A 一致** → 需进一步确认 apply 解析的是谁的 claim：若 200 且仅因会话本身是管理员，仍不构成提权证据（A 组也 200）；此时需用**非管理员会话**才能区分，列为剩余 unknown。
     - B 组 **200 且出现 A 组没有的管理员专属行为**（若能在只读端点观察到）→ 高风险，立即停止并升级。
- **若无法注入头**（多数浏览器自动化限制）：
  - 记录"受工具限制未完成 L2"，并给出手工替代：用户在浏览器 DevTools 里手工执行同样的只读 fetch（Lead 提供一段**不含凭据**的代码片段），把返回状态码/错误码告诉 Lead；不要求用户粘贴 cookie/响应全文。
  - §0.2 保持 BLOCKED，但 L1 正向证据可先入档。

## 4. 结果如何影响门禁

- L1 成功 + L2 显示伪造头被拒绝（400/403）→ 可把 §0.2 的"头剥离/覆盖"未知项降级为"已观测伪造头不能覆盖会话身份"，但 §0.2 仍需其它条目（安全码/2FA、路径穿越、写路径未测）才能整体 PASS。
- L1 成功 + L2 无法执行 → §0.2 仍 BLOCKED，登记"受工具/授权限制未完成"。
- 任何异常（伪造头被接受且出现管理员行为）→ 立即停止、升级为高风险发现，不继续任何设备操作。

## 5. 不做的事

- 不向生产发写请求、不重放 cookie、不把会话导出到文件、不修改任何配置/服务、不安装任何东西。
- 不把"手工带 `x-trim-isadmin: true` 的 socket 烟雾"当作身份来源或授权证明（检查单 §0.2 原话）。
