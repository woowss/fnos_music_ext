# 离线“超清母带优先、最佳可用音质回退”策略

合同：`FNMEXT-BEST-AVAILABLE-QUALITY-20261031-01`。基准提交：`5f2feb42a9a1185433785f06369e7989d1bfb06d`。

## 范围

`proxy/manual_save_best_quality.py` 是独立、离线的合成策略。它只接收调用方提供的结构化证据，并要求通过注入的独立 verifier 对本次完整证据快照进行验证。模块不连接网易云或其他网络，不访问账号、Cookie、Provider API、Media API、下载接口、文件系统、NAS 或保存/转换流水线；不获取或处理真实音频。它不会连接生产路由，也不会触发任何下载或写入。

请求偏好固定为抽象 `ULTRA_MASTER`。策略复用严格母带候选中的抽象 `QualityTier`，并要求完整顺序严格等于：

1. `ULTRA_MASTER`
2. `HI_RES`
3. `LOSSLESS`
4. `HIGH`
5. `STANDARD`

上述名字仅为内部抽象档位。它们不是网易云服务端质量证明，也不说明具体编码、码率或采样率。

## 选择条件

每首歌必须提供完整档位清单及与各档一一对应的状态；清单缺失、重复、乱序或 verifier 未确认完整覆盖时拒绝。每条状态须绑定同一 `song_id`、`request_id`、`attempt_id`、不透明的 `account_id`、来源标识、映射标识与映射版本，并具有在请求之后签发且当前仍有效的时间范围。verifier 必须分别确认来源身份、映射版本和账号身份，确认完整排序、每档状态和整组规范化快照摘要；信任报告也必须绑定相同账号。账户无权益的证据只有在账号身份已独立验证后才可用于回退。

- 只有 `AVAILABLE` 且明确有权益、非试听、内容完整、时长匹配的档位才可选。
- 低档只有在所有更高档均有新鲜、可信、与本次请求及账号绑定的证据时才能选择：来源明确证明该档未提供（`UNAVAILABLE / NOT_OFFERED`），或可信证明此账号无该档权益（`UNAVAILABLE / ACCOUNT_NOT_ENTITLED` 且 `rights_status=NOT_ENTITLED`）。
- 策略按严格顺序从高到低检查候选。在找到候选之前遇到 `UNKNOWN`、超时、权益未知、试听、内容不完整或时长不匹配时拒绝，不能把更高档的未知状态当作不可用。
- 一旦某档已通过验证并成为当前最高可用候选，其下档位的 availability unknown、权益未知或试听状态不否定该候选；但下档的完整状态快照仍必须由 verifier 覆盖，且 song/request/attempt/account 绑定、来源/映射、有效时间和状态结构必须完整、无矛盾。任何档位发生跨账号、账号未经验证、字段损坏、伪造映射、过期或结构矛盾仍会拒绝整次评估。
- 不能把其他账号的权益状态、未认证的账号权益声明、权益未知/拒绝或来源超时当作回退依据；跨账号证据会拒绝。
- 所有档位均明确不可用时拒绝；不会静默改选，也不会把降档结果标成母带。

每次单曲验证前后都会读取注入时钟。歌单复用同一单调时钟观察器，任一读数无效、异常或倒退都会使整批失败并清除所有选中结果。逐曲完成后再读取最终时刻，并对每首已选曲目的请求、档位映射和全部档位证据重新检查过期及最大年龄；过期项保留在逐项结果中并改为拒绝。时钟回调之后也会复核原输入与冻结快照。歌单输入先限制为 1–500 首，再冻结每首的请求、映射、证据和嵌套结构；跨曲字段变动、项目替换、增删或结构变化会让整批失败。逐曲拒绝仍保留在结果中，且只有所有项目均完成并选中时 all_selected 才为真；部分完成或失败不会报告为整单成功。

## 结果与不可推断事项

`QualityResult` 只返回请求抽象档位、选中的抽象档位、是否回退和固定原因码。异常文本、原始响应、URL、Cookie、文件路径及其他输入内容不进入结果。所有单曲/歌单结果及模块级常量都固定 `production_ready=False`。

策略不读取或解释 `jymaster`、provider quality label、codec、FLAC、文件扩展名、码率、采样率、URL 或请求参数。上述字段不能证明网易云真实交付质量。离线测试中的 verifier 是内存假对象，其返回“已验证”只用于测试策略如何处理信任结果，不能证明任何真实 verifier、来源签名、账号权益、服务端语义或映射可靠。
