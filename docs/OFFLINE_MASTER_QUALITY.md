# 离线“超清母带”音质证据策略

合同：FNMEXT-STRICT-MASTER-QUALITY-20261031-01。

## 范围

proxy/manual_save_quality_policy.py 是隔离的合成策略：它只评估调用方提供的、已脱敏的单曲质量证据，不连接网易云、不取音频、不解密 NCM、不调用保存流水线、不写文件、不访问 NAS，也不新增 WebUI、API 或生产路由。

evaluate_quality() 要求证据同时满足以下条件：

- 与本次请求 ID、唯一尝试 ID 和选中曲目 ID 精确绑定；旧重试证据不能复用。
- 用户确认状态为真，实际等级与请求等级精确一致。
- 独立权利状态为已验证，明确无试听，且明确完整。
- 有效时长与曲目展示时长相差不超过 2 秒。
- 证据由独立注入的验证器确认来源可信，且验证器独立确认当前映射 ID；无映射或映射 ID 不一致时拒绝。
- 通过注入的可信时钟在来源验证器调用前后各读取一次；时钟异常、返回非整数或倒退均拒绝。返回后重新校验请求与证据全部字段，并以第二次读数重验时效，因此验证期间过期或跨过 300 秒新鲜度边界会拒绝。

任一字段缺失、类型异常、未知、冲突、过期、对象字段被删除、验证器或时钟抛错均以固定原因码拒绝；公共策略入口捕获属性读取异常并返回固定脱敏结果。失败结果不携带输入字段、异常文本、URL、Cookie 或原始响应。歌单先限制为不超过500首，并在任何验证器回调前冻结每项请求与证据的全部字段值；策略只用这些字段副本逐曲验证。验证期间复核所有原始项（包括已评估与未评估曲目）的请求/证据字段及列表、配对结构，检测到增删替换、字段改写或删除、对象损坏及可观察到的并发修改时，整体以固定脱敏原因拒绝，不能把修改后的清单当作原始清单完整通过。无法安全快照时不调用验证器。不继承相邻曲目的证据，不静默降档。策略不会选择低档重试或把低档结果标为母带。

## 档位映射边界

策略使用抽象内部等级，不接收提供商档位字符串。jymaster、hires、FLAC/其他格式名、码率、采样率、扩展名及请求参数本身都不能证明“超清母带”。仓库中 musicbox-service/app.py 的质量白名单及 proxy/app.py 的质量阶梯只是允许请求的标签，不能独立证明标签到实际音质的可信映射。

因此策略不内置“网易云档位 → 超清母带”映射。只有独立验证器在可信来源证据上确认来源及精确映射后，才可能得到离线的 MATCHED 结果。仓库没有在本次任务中添加真实来源验证器或验证过的等级映射。

## 结果与安全限制

即使所有合成条件通过，QualityResult.production_ready 和模块级 PRODUCTION_READY 仍固定为 False。这表示“测试提供的证据字段与策略相符”，不表示网易云确实交付母带，不表示当前账号拥有下载权益，也不授权或证明下载、转换、发布、入库或上线。

测试中的验证器是内存假对象。它只能证明策略正确要求并处理验证报告，不能证明任何生产验证器、来源签名、服务端字段或等级映射可信。后续接入必须另行取得可审阅的来源契约，验证字段绑定、签名/来源身份、映射及权益语义；接入生产前还需要独立设计、审查和真实设备验收。

## 验证

从仓库根目录执行：

~~~powershell
python -B -m unittest -v offline_tests.test_manual_save_quality_policy
~~~

测试仅使用合成请求、合成证据、内存验证器和可控时钟，覆盖绑定、重试复用、时间窗口、验证期间过期/跨边界、时钟倒退/异常/字段缺失、对象字段删除、验证器修改输入、等级错配/低档、来源与映射验证、权限、确认、无试听、完整性、时长、异常脱敏以及歌单逐曲处理、500首边界、验证器回调增删替换、跨项改写（前序及后续曲目）、字段删除、并发改写及无法快照时失效关闭。通过结果不构成真实账号、网易云源、下载音频、NCM 转换、音质等级或 NAS 文件写入证据。
